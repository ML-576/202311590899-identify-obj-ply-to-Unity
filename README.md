# 上机02 模型的表达 —— OBJ/PLY 模型识别与浏览

## 项目简介
基于 Unity 的三维模型浏览器，程序化解析 OBJ / PLY（ASCII 与二进制）文件，
生成 Mesh 并支持自由视角浏览（旋转 / 平移 / 缩放）、模型信息展示与加载进度反馈。

## 目录
- `Identify OBJ and PLY/` —— 全部源码（C++ 解析库 + Unity C# 脚本 + 原生插件 DLL）
- `obj数据/` 、 `ply数据/` —— 测试用模型数据

## 测试使用 
用 Unity 打开 `UnityAssets` 内容导入工程，运行场景后通过界面选择模型文件加载。
